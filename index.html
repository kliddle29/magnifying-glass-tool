Magnifying Glass

A restrained hover-magnifier for any page. Click the toolbar icon to turn it on, then hover to look closer at whatever is under the cursor. Click again to turn it off.

This is a browser extension, not a webpage

There is nothing to demo on this page itself — the tool only runs once it is installed and pointed at another site. This page is the project's documentation and submission link.

Install it (unpacked, for grading)

  1. Download or clone this repository.
  2. Open chrome://extensions in Chrome.
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select this project's folder.
  5. Visit any site, click the extension's toolbar icon once, then hover.
